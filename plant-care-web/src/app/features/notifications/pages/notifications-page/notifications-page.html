Install on iPhone or iPad

For push reminders, use the Home Screen app on iOS or iPadOS 16.4 or later.

  1. Open PlantCare in Safari, open the Share menu, then choose Add to Home Screen.
  2. If shown, keep Open as Web App enabled, then tap Add.
  3. Open PlantCare from its new icon and sign in if needed.
  4. Return to Notifications → Reminder settings and tap Enable push reminders. Allow notifications when asked.

Permission is requested only when you tap Enable push reminders. Device notification settings and Focus can affect delivery.
