# Care notification illustrations

Original PlantCare vector artwork: watering (drop), fertilizing (plant-food
bottle), misting (spray bottle), pruning (shears), repotting (pot with soil).
The editable `care-*.svg` files are the sources; each matching PNG is a transparent
192 × 192 raster export, rendered with Chromium at device scale 1. No external
image downloads, fonts or reference-photo licenses are involved. Project rights
reserved terms apply to these original illustrations.

Keep the PNG paths synchronized with WebPushDeliveryService. These are static
cartoon-style illustrations; actual notification layout and the separate system
badge are controlled by the device. Existing app-installation icons are unchanged.
