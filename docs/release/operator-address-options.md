# Operator address options to review

Prepared 2026-10-21. The owner chose to review options before providing any postal
address. No street address is approved for publication and none is inferred from

| Option | Practical trade-off | What must be established |

| The real home address from which the operator runs the project | No separate address-service subscription, but exposes the home address publicly and in source history if committed. | Owner explicitly accepts publication; the address is suitable for the actual operator/service and can receive formal correspondence. No provider or purchase is selected here. | Before paying, verify actual use rights, whether the arrangement meets the intended legal-notice requirements, acceptance of formal service/correspondence and forwarding, total recurring charges and cancellation terms. A marketing claim alone is not verification. |

Where DDG §5 applies, the requirement concerns the provider's name and address
where established. A city name/email alone is not that address, and a PO box is
not a substitute for the required street address. Do not assume every virtual
mailbox or forwarding subscription qualifies. A personal project label does not
by itself settle applicability, especially for the intended future advertising.

For this project's EUR15 monthly budget, no additional address subscription is
recommended or authorized by this review. First decide whether using a suitable
real operating address publicly is acceptable. If not, assess a suitable paid
arrangement and its cost before wider launch; keep the launch gate open rather
than inserting an unsuitable address. Development can continue while this choice
is pending. This does not determine that current public staging is exempt.
