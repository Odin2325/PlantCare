# Lettuce, zucchini and currant cultivar batch

Prepared locally on 2026-10-31. No push, CI or deployment is part of this increment.

Six cultivars expand the reviewed catalog to **244 entries / 102 cultivars**:

| Entry | Distinguishing guidance | Reviewed primary source |
| --- | --- | --- |
| Lettuce (Lollo Rossa) | Red curled leaves; outer-leaf or whole-head harvest | [RHS profile](https://www.rhs.org.uk/plants/119367/lactuca-sativa-lollo-rossa/details) |
| Zucchini (Defender) | Open habit and green fruit; resistance does not replace inspection | [RHS profile](https://www.rhs.org.uk/plants/112370/cucurbita-pepo-defender/details) |
| Zucchini (Parador) | Yellow cylindrical fruit; colour alone is not maturity | [RHS courgette guide](https://www.rhs.org.uk/vegetables/courgettes/grow-your-own) |
| Zucchini (Astia) | Compact habit; a large drained container is still necessary | [RHS courgette guide](https://www.rhs.org.uk/vegetables/courgettes/grow-your-own) |
| Redcurrant (Rovada) | Later fruiting; retain a permanent branch framework | [RHS profile](https://www.rhs.org.uk/plants/73881/ribes-rubrum-rovada-r/details), [redcurrant guide](https://www.rhs.org.uk/fruit/redcurrants/grow-your-own) |
| Blackcurrant (Ben Sarek) | Compact shrub; renew older stems during dormancy | [RHS profile](https://www.rhs.org.uk/plants/85003/ribes-nigrum-ben-sarek-b/details), [blackcurrant guide](https://www.rhs.org.uk/fruit/blackcurrants/grow-your-own) |

Currants are placed in Fruit, not Trees. Each new entry includes English common
names, two English search aliases and growing/harvest guidance. Watering intervals
remain prompts to check moisture, adjusted for weather, container and season.
No automatic feeding schedule, exact local harvest date or temperature limit is
invented. RHS timing and performance descriptions are not guarantees for Germany.
All 238 preceding records are unchanged.

## Photography

The [Lollo Rossa source](https://commons.wikimedia.org/wiki/File:Lollo_rossa_Setzlinge.JPG)
explicitly identifies the cultivar and seedlings photographed in Germany. Its
CC BY-SA 3.0 licence and contents were reviewed. The photograph uses the
Wikimedia-provided 960-pixel thumbnail with no further edits. Alt text identifies
the young plants; this is not a growth-progression sequence. Author, original
title, source, licence, thumbnail disclosure, byte size and checksum are retained
in the public credits and manifest.

The other five new cultivars use the approved named pending placeholder. Generic
redcurrant results were rejected because the source description did not establish
the cultivar. Search-result relevance alone does not establish identity.

The cultivar coverage matrix includes every new entry. Existing assets and their
manifest records are preserved.
