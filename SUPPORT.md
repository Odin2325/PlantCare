# PlantCare support

PlantCare is currently a learning project in staging. It has not been released
as a production service. See the [user guide](docs/user-guide.md) and
[known limitations](docs/known-limitations.md) first.

## General questions and bugs

Search [GitHub Issues](https://github.com/Odin2325/PlantCare/issues) for an
existing report, then open an issue if needed. Include:

- What you were trying to do, the steps, and expected versus actual behavior.
- Browser/device versions and whether you used a browser tab or installed app.
- Whether the problem persists after returning online and accepting Update now.
- A redacted screenshot or the exact non-sensitive error message, if useful.

GitHub issues are public. Do not include passwords, confirmation/reset links,
private calendar-feed URLs, push endpoints, tokens, account emails, personal
plant notes, or unredacted logs/screenshots. Use a made-up plant name in examples.
There is no guaranteed response time for this learning project.

## Account, privacy and security requests

Do not post private account information, data-access/deletion requests, or
exploitable security details in public issues. A confidential contact channel is
not yet published. Establishing that channel and a tested account-data handling
procedure is a requirement before opening the service to a wider audience.

Plant archiving preserves data; it does not delete an account or erase its data.
There is currently no self-service account deletion or account-data export.
